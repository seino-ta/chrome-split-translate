# Split Translate

<img src="icons/icon128.png" width="64" alt="">

[English](README.md)

今見ているページの原文と翻訳を、Chrome の分割表示で左右に並べる拡張機能です。スクロールとページ遷移は左右で同期するので、見比べながらそのままサイトを操作できます。

- 翻訳は Chrome 内蔵の [Translator API](https://developer.chrome.com/docs/ai/translator-api) で端末内で行います。ページの内容は外部に送信されません。
- 分割表示には Chrome 155 で追加された [Split View API](https://developer.chrome.com/docs/extensions/reference/api/tabs)（`tabs.create` の `splitWithTabId`）を使います。

## 必要なもの

- Chrome 155 以降（デスクトップ版）

## インストール

1. `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダ（`manifest.json` があるフォルダ）を選ぶ
3. ツールバーのパズルアイコンから「Split Translate」をピン留めする

インストールしたらすぐに使えます。既定では、英語をブラウザの表示言語に翻訳します。表示言語が日本語なら、英語 → 日本語です。

## 使い方

1. 翻訳したいページでツールバーのボタンを押す
   - そのサイトで初めて使うときは、サイトへのアクセス許可を求められる
2. 右側に同じページが分割表示で開き、翻訳される
   - 分割表示中はツールバーのボタンに「●」が付く。ボタンにマウスを乗せると、今の状態が表示される
3. どちらかをスクロールすると、もう片方も同じ位置に移動する
4. どちらかで別のページを開くと、もう片方も同じページを開く
5. もう一度ボタンを押すと翻訳タブが閉じる。分割表示を手動で解除しても同期は止まる

初回は言語ペアごとに翻訳モデルのダウンロードが必要です。翻訳タブの右下に「翻訳を開始」ボタンが出たら押してください。設定画面の「翻訳モデルを準備」で、あらかじめダウンロードしておくこともできます。

操作（入力・コメント投稿・ボタン操作など）は左右どちらのタブでも普通にできます。クリックや入力は同期しないので、二重に送信されることはありません。入力欄（textarea など）とコード（`code` / `pre`）は翻訳しません。

## 設定

拡張機能のボタンを右クリック →「オプション」で開きます。変更はすぐに保存されます。

| 項目 | 既定値 | 内容 |
|---|---|---|
| 原文 / 翻訳先 | 英語 → ブラウザの表示言語 | 翻訳する言語の組み合わせ |
| すべてのサイトで許可する | オフ | オフのときはサイトごとに初回だけ許可を求める。オンにすると確認なしでどのサイトでも使える |
| スクロールを同期する | オン | |
| ページ遷移を同期する | オン | |

サイトごとの許可は `chrome://extensions` →「Split Translate」の「詳細」→「サイトへのアクセス」で確認・取り消しできます。

## 仕組み

- `src/background.js`: 分割表示の開始と終了、原文タブと翻訳タブのペア管理、ページ遷移の同期、スクロール情報の中継
- `src/content.js`: 翻訳（テキストノード単位で置き換えるので DOM 構造は変わらない）とスクロール同期。分割表示中のタブにだけ注入する
- `src/options.html` / `src/options.js`: 設定画面
- `src/shared.js`: 設定の既定値など
- `_locales/`: 表示する文言（英語・日本語）

スクロール同期では、画面の上から 25% の位置にある要素と、その要素内での位置を相手のタブに送ります。左右で DOM 構造が同じなので、翻訳で文章の長さが変わっても同じ段落が同じ高さに来ます。

## 制限

- 翻訳は、ページ内のテキストのまとまり（テキストノード）ごとに行います。そのため `Click <b>here</b> to continue` のように太字やリンクで分かれた文は部分ごとに訳され、不自然になることがあります。
- 左右のページで表示内容が違う場合（片方だけ折りたたみを開いた、など）は、要素の対応が取れず、スクロール量の割合で合わせます。
- 分割表示中に、アクセスを許可していない別のサイトへ移動すると、そのページは翻訳されません。
- `chrome://` のページや Chrome ウェブストアでは使えません。iframe の中も翻訳しません。

## 開発・テスト

E2E テストは、Playwright 同梱の Chromium（Chrome for Testing）に拡張機能を読み込んで動かします。Split View API と `--load-extension` を使うため、Chrome for Testing は 155 以降が必要です。確認する内容は次のとおりです。

- 分割表示の開始と終了
- 翻訳
- Chrome のページ翻訳との共存
- スクロール同期
- ページ遷移の同期

```sh
npm install
npm test            # 初回は Chromium をダウンロードします
HEADED=1 npm test   # ブラウザを表示して実行
```

テストでは、拡張機能を一時ディレクトリにコピーして使います。サイトへのアクセス許可のダイアログは自動操作できないので、コピーでは `<all_urls>` を最初から許可しておきます。また Translator API を `[ja] 原文 原文` を返す偽物に差し替えるので、翻訳モデルのダウンロードは要りません。

表示言語ごとの文言も確認するときは、`LOCALE=en` または `LOCALE=ja` を付けて実行します。付けない場合は、ブラウザが起動したときの言語のまま実行し、表示言語ごとの確認は省きます。

macOS の Chrome は、拡張機能の表示言語を `--lang` ではなくシステムの言語設定から決めます。そのため、実行前に Chrome for Testing の言語を設定し、終わったら設定を削除してください。

```sh
defaults write com.google.chrome.for.testing AppleLanguages '(en)'
LOCALE=en npm test
defaults delete com.google.chrome.for.testing AppleLanguages
```
